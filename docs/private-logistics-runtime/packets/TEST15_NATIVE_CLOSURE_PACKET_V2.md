## Assembly Inconsistencies Reported (inherited from V1 packet / cached files)

These are reported honestly; packaging does not repair native evidence.

1. **Rail raw section in V1 was truncated/misaligned.** V1 claimed `panel_745350_final.c` Lines: 1864 and cited `window+0x310+idx*4` (orig lines 1619-1624) and `/49` (orig line 904), but the V1 raw rail section contained only ~1187 lines and the byte at the claimed offset was `}` not the cited literal. V2 packages the complete 79895-byte file via Base64.
2. **Creator row address off by 0x24.** V1 cited VA `0x1406EE83F` for bytes `48 C7 43 18 00 00 00 00`; the actual disasm has those bytes at `0x1406EE81B` (V1 packet line 330 shows `0x1406EE83F: 48 83 C8 FF`). Reported, not corrected.
3. **Ctor rows re-ordered/repeated in V1.** V1 packet lines 1629-1631 list `0x14025C7E8` then `0x14025C7E5` then `0x14025C7E8` again; the original file is strictly ascending (`0x14025C7E5`, then `0x14025C7E8`). Reported, not corrected.
4. **Ctor mnemonic/bytes mismatch in V1 text.** V1 packet line 1508 prints `14025c58b: 48 89 67 08 ... MOV [RDI+8],RSI`, but bytes `48 89 67 08` decode to `MOV [RDI+8],RSP`. The cached original file has bytes `48 89 77 08` = `MOV [RDI+8],RSI` (internally consistent). The V1 text had a typo (`67` vs `77`). Reported, not corrected; the cached file is authoritative.
5. **R9 not resolved.** At the insertion CALL, `[RSP+0x20]` is argument five, not R9's home slot; the value stored there is the address of a stack local holding `window*`, not `window*` directly. Window field `+0x34` values 8/9 are insert-position selectors, not building types 43/52. The building type is `*(uint*)(*(longlong*)(lVar22+0x318)+0x360)` (0x2b=43 road, 0x34=52 rail). R9 ambiguity is preserved; closure not asserted on R9.
6. **Index file hash drift.** V1 stated `docs/ghidra-index/6EE2A0.md` = 4836 bytes / `C38FFFDD...`. The cached file now (and at HEAD) is 5768 bytes / `5B0CFD3C...` (post-update). V2 packages the current cached file and records its actual hash. V1's stated hash is stale.
7. **Excerpt vs full-file hash distinction.** V1 labelled `agent1_install_connected_decomp.c` as 5439 bytes but only embedded lines 86-101. V2 packages the full 5439-byte file and separately provides the 86-101 excerpt with its own hash, explicitly labelled PARTIAL.

#!/usr/bin/env python3
# verify_test15_v2.py
# Verifies TEST15_NATIVE_CLOSURE_PACKET_V2.md by decoding every packaged artifact
# and comparing byte-for-byte to the original cached file.
import base64, gzip, hashlib, os, re

ROOT = r"C:\WRSRE"
PACKET = os.path.join(ROOT, "TEST15_NATIVE_CLOSURE_PACKET_V2.md")
text = open(PACKET, encoding="utf-8", newline="").read()

def sha256_bytes(b):
    return hashlib.sha256(b).hexdigest().upper()

results = []
all_ok = True

# --- Artifacts ---
art_re = re.compile(r"### Artifact (\d+): `([^`]+)`\n\nRole: .*?Bytes: (\d+) \| SHA-256: `([0-9A-F]+)`", re.S)
for m in art_re.finditer(text):
    idx, rel, nbytes, stated_hash = m.group(1), m.group(2), int(m.group(3)), m.group(4)
    # find the base64 block after this header
    start = m.end()
    block = re.search(r"```base64\n(.*?)\n```", text[start:], re.S)
    if not block:
        results.append(("ARTIFACT", idx, rel, "FAIL", "no base64 block"))
        all_ok = False
        continue
    enc = block.group(1).replace("\n", "")
    try:
        raw = gzip.decompress(base64.b64decode(enc))
    except Exception as e:
        results.append(("ARTIFACT", idx, rel, "FAIL", f"decode error: {e}"))
        all_ok = False
        continue
    orig_path = os.path.join(ROOT, rel)
    if not os.path.exists(orig_path):
        results.append(("ARTIFACT", idx, rel, "FAIL", "original missing on disk"))
        all_ok = False
        continue
    orig = open(orig_path, "rb").read()
    h = sha256_bytes(raw)
    ok = (len(raw) == nbytes and h == stated_hash and raw == orig)
    results.append(("ARTIFACT", idx, rel,
                    "PASS" if ok else "FAIL",
                    f"decoded={len(raw)} stated={nbytes} orig={len(orig)} hash_match={h==stated_hash} bytes_match={raw==orig}"))
    if not ok:
        all_ok = False

# --- Excerpts ---
exc_re = re.compile(r"### Excerpt: (.+?)\n\nSource: `([^`]+)` lines (\d+)-(\d+) \| Excerpt bytes: (\d+) \| Excerpt SHA-256: `([0-9A-F]+)`", re.S)
for m in exc_re.finditer(text):
    label, rel, s, e, nbytes, stated_hash = m.group(1), m.group(2), int(m.group(3)), int(m.group(4)), int(m.group(5)), m.group(6)
    start = m.end()
    block = re.search(r"```text\n(.*?)\n```", text[start:], re.S)
    if not block:
        results.append(("EXCERPT", "-", label[:40], "FAIL", "no text block"))
        all_ok = False
        continue
    # The fenced content: block.group(1) is between ```text\n and \n```. Re-add trailing newline to match original?
    # Original excerpt extraction used b"".join(lines) which keeps line endings. The fenced block strips the final newline before ```.
    # We need to reconstruct: content as stored in fence + "\n" (the newline that preceded closing fence).
    content_str = block.group(1)
    # The fence was written as w(txt); if txt didn't end with \n, we added "\n". So decoded fence content + "\n" = original excerpt bytes IF original ended with \n.
    # Determine original excerpt bytes from disk:
    orig_path = os.path.join(ROOT, rel)
    if not os.path.exists(orig_path):
        results.append(("EXCERPT", "-", label[:40], "FAIL", "original missing"))
        all_ok = False
        continue
    orig_lines = open(orig_path, "rb").read().splitlines(keepends=True)
    sel = b"".join(orig_lines[s-1:e])
    # Candidate decoded bytes from fence: try content_str + "\n"
    cand1 = (content_str + "\n").encode("utf-8")
    cand2 = content_str.encode("utf-8")
    if cand1 == sel:
        dec = cand1
    elif cand2 == sel:
        dec = cand2
    else:
        dec = cand1  # report mismatch
    h = sha256_bytes(dec)
    ok = (len(dec) == nbytes and h == stated_hash and dec == sel)
    results.append(("EXCERPT", f"{s}-{e}", rel,
                    "PASS" if ok else "FAIL",
                    f"decoded={len(dec)} stated={nbytes} orig={len(sel)} hash_match={h==stated_hash} bytes_match={dec==sel}"))
    if not ok:
        all_ok = False

# Print
