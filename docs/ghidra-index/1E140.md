# FUN_14001E140 — context panel table insertion helper

**RVA:** `0x1E140` (preferred VA `0x14001E140`).
**Signature (Ghidra recovered):** `longlong *FUN_14001e140(longlong *param_1, longlong *param_2, undefined8 *param_3, undefined8 param_4, undefined8 *param_5)`. ABI not independently verified; argument roles below are from instruction-level decode, not from this signature.
**Purpose:** inserts one element (window*) into the context panel table at `context+0xCAC0` (param_1), at the insertion address param_3, growing/reallocating or shifting as needed. Delegates element construction to `FUN_14001E8C0(dest, count, src)`.

## Table-element store

- Epilogue: `MOV RAX, [RDI]` (begin); `LEA RCX, [RAX + RBP*8]` (inserted element address = begin + insertion_index*8); `MOV RAX, R14`; `MOV [R14], RCX` (writes inserted element address to output slot param_2). Return value = param_2.
- Post-insert clearing/bulk-propagation: from insertion address (param_3) through end-8, each slot set to window* (loop at 0x14001e316-0x14001e32d and 0x14001e380-0x14001e393). This is the "bulk-propagate over total target count" edge.

## Branch coverage

- Capacity-full (growth): reallocates via `FUN_1400019E0(newcap,8)`, constructs inserted element from param_5, memmoves before/after, frees old buffer, updates begin/end/capacity, then bulk-fills slots from insertion point to new end with window*.

- Capacity-available, insertion in middle: memmove shifts [param_3,end) right by 8, constructs 1 element, end++, then bulk-fills from param_3 to end-8 with window*.

## R9 (param_4) status

Unused. Saved to `[RSP+0x20]` at entry (0x14001e140, bytes `4C 89 4C 24 20`), immediately clobbered by capacity load (`MOV R9, [RDI+0x10]` at 0x14001e16a). No instruction reads the original param_4. Proven unused by exhaustive scan of all three disasm parts: only one write to `[RSP+0x20]` at entry, no read.
